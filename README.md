# Cortex

**Agentic RAG over your live work data, with explainable memory and auditable evidence.**

Ask *"What changed in Project Atlas this quarter, and what are the risks?"*. Cortex plans sub-questions, searches Gmail, Calendar, Drive, Notion, Slack, GitHub and the web in parallel, recalls what you told it matters, and returns a verified, cited answer. It also flags contradictions between sources and shows the whole reasoning trace.

- **Free:** Puter.js user-pays LLMs + a free-tier failover pool, Oracle Always Free, Composio, Firecrawl and LangSmith free tiers
- **Zero-config connectors:** one-click OAuth, no tokens
- **Explainable memory:** Oracle Agent Memory with salience-based promotion, provenance, pin/edit/forget
